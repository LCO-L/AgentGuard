AgentGuard 개인정보처리방침

시행일: 2026-07-27 · 적용 대상: AgentGuard 크롬 확장 프로그램 · 웹 서비스

요약 — 세 가지 원칙

  • 온디바이스 우선 — 페이지 인라인 검사(밑줄)와 입력창 보호는 브라우저 안에서만 동작하며 아무 데도 전송하지 않습니다.
  • 비저장 — 사용자가 요청한 상세 검사에서도 서버는 원문·API 키·마스킹 매핑을 저장하지 않습니다.
  • 비판매 — 어떤 데이터도 판매·광고·제3자 제공에 사용하지 않습니다. 추적기·분석 스크립트도 없습니다.

1. 수집·처리하는 정보

① 사용자가 검사를 요청한 콘텐츠

우클릭으로 검사를 선택한 링크·이미지 주소·선택 텍스트, 끌어다 놓은 파일, "이 페이지 검사"를 눌렀을 때의 페이지 텍스트가 사용자가 설정한 백엔드(기본: 본인 컴퓨터의 로컬 서버, 또는 공개 데모 서버)로 전송되어 검사됩니다. 서버는 위험 판정에 필요한 처리만 하고 원문을 저장하지 않습니다. 검사 이력에는 메타데이터(시각·유형·등급·발견 규칙 수)만 남습니다.

② AI 입력창 보호

ChatGPT 등 AI 사이트의 입력창 내용은 브라우저 안에서 로컬로만 검사됩니다(agscan.js). 마스킹을 선택하면 치환도 브라우저 안에서 수행되며, 원문·복원 매핑은 외부로 나가지 않습니다.

③ 설정값

백엔드 주소, 선택한 AI 엔진, 사용자가 직접 입력한 API 키(BYOK)는 이 브라우저의 chrome.storage.local 에만 저장됩니다. 키는 검사 요청 시 헤더로만 전달되고 서버에 저장되지 않습니다.

④ 익명 식별자

검사 이력을 브라우저 단위로 분리하기 위한 무작위 익명 ID(X-AG-Client)를 사용합니다. 계정·이메일·이름 등 개인 식별 정보는 수집하지 않습니다.

2. 하지 않는 것

  • 개인정보 판매·대여·광고 목적 제공 — 없음
  • 서드파티 분석·추적 스크립트 — 없음
  • 브라우징 기록 수집 — 없음 (검사는 사용자가 명시적으로 요청할 때만)
  • 원문·비밀값·마스킹 매핑의 서버 저장 — 없음 (비저장 원칙)

3. 보관·삭제 및 문의

검사 이력 메타데이터는 최근 항목만 순환 보관되며, 온프레미스/로컬 설치에서는 전적으로 사용자 통제하에 있습니다. 소스 코드는 MIT 라이선스로 공개되어 있어 처리 과정을 직접 확인할 수 있습니다: github.com/LCO-L/AgentGuard. 문의·삭제 요청은 GitHub 이슈 또는 저장소에 기재된 연락처로 주세요.

AgentGuard Privacy Policy (English)

Effective: 2026-07-27 · Applies to: the AgentGuard Chrome extension and web service

Summary — three principles

  • On-device first — inline page checks (underlines) and AI input-box protection run entirely inside your browser and transmit nothing.
  • No storage — even for detailed scans you request, the server never stores originals, API keys, or masking mappings.
  • No selling — no data is sold, used for ads, or shared with third parties. No trackers or analytics scripts.

1. What we process

Content you explicitly ask to scan (a right-clicked link/image/selection, a dropped file, or page text when you press "scan this page") is sent to the backend you configure — by default your own local server, or the public demo server — for analysis. The server processes it only to produce a verdict and does not store the original. Scan history keeps metadata only (time, type, grade, rule count).

AI input-box guard: text in AI chat inputs (ChatGPT etc.) is scanned locally in your browser; masking is applied locally, and originals/restore mappings never leave your machine.

Settings (backend address, chosen engine, your own BYOK API key) live only in chrome.storage.local. Keys travel only as request headers and are never stored server-side.

Anonymous ID: a random identifier (X-AG-Client) separates scan history per browser. We collect no accounts, emails, names, or other personal identifiers.

2. What we never do

  • Sell, rent, or share personal data; no advertising use
  • No third-party analytics or tracking scripts
  • No collection of browsing history — scanning happens only on your explicit request
  • No server-side storage of originals, secrets, or masking mappings

3. Retention & contact

Scan-history metadata is kept on a rolling basis; on local/on-prem installs it is fully under your control. The source code is MIT-licensed and auditable: github.com/LCO-L/AgentGuard. For questions or deletion requests, open a GitHub issue or use the contact in the repository.
