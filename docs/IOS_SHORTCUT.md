# 📱 아이폰에서 "꾹 눌러 검사" 하는 두 가지 방법

데스크톱은 크롬 익스텐션의 **우클릭**으로, 아이폰은 **공유 시트**로 검사합니다.
(Safari에서 링크·문구를 꾹 누르면 뜨는 그 "공유" 메뉴)

## 방법 A — PWA 공유 타겟 (설치 1분, 코드 0)

AgentGuard 대시보드는 PWA라 **공유 시트에 등장**합니다.

1. 아이폰 Safari로 백엔드 주소(예: `http://<맥의 IP>:8000`)를 엽니다.
2. 하단 **공유** 버튼 → **홈 화면에 추가**.
3. 이제 어떤 앱에서든 링크·텍스트를 선택 → **공유** → **AgentGuard**를 고르면
   대시보드가 열리며 **자동으로 검사**합니다.

> 원리: `manifest.webmanifest`의 `share_target`이 공유된 `url`/`text`를 대시보드로
> 넘기고, 대시보드가 이를 받아 즉시 `/v1/scan/url` 또는 `/v1/scan/text`로 검사합니다.

## 방법 B — iOS 단축어(Shortcuts)

파일까지 검사하고 싶다면 단축어가 유연합니다. 아래대로 한 번만 만들면
공유 시트에 **"AgentGuard로 검사"**가 생깁니다.

1. **단축어** 앱 → 새 단축어 → 우측 상단 (i) → **공유 시트에 표시** 켜기,
   받는 항목: URL·텍스트·파일.
2. 액션 추가:
   - **"URL 콘텐츠 가져오기"**
     - URL: `http://<맥의 IP>:8000/v1/scan/url` (텍스트/파일이면 `/v1/scan/text`)
     - 방법: `POST`, 본문: `JSON`
     - JSON: `{ "url": <단축어 입력> }`  (텍스트면 `{ "text": <단축어 입력> }`)
     - (선택) 헤더 `X-AI-Provider: ollama` 등으로 판단 엔진 지정
   - **"사전에서 값 가져오기"** → 키 `card` → `headline`, `action`
   - **"알림 표시"** 또는 **"결과 보기"** 로 통역 카드 문구 표시
3. 이름을 "AgentGuard로 검사"로 저장.

이제 링크·문구를 **꾹 눌러 → 공유 → AgentGuard로 검사** 하면 위험 여부가 바로 뜹니다.

> 온디바이스 원칙: 방법 A·B 모두 검사는 로컬 백엔드(내 맥/서버)에서 처리하고
> 원본은 저장하지 않습니다. 완전 오프라인을 원하면 판단 엔진을 Ollama로 두세요.
